# GNS3-guiden

En interaktiv webbsida (på svenska) som förklarar nätverksemulatorn GNS3: arkitektur, arbetsflöde, ett mini-labb där du bygger topologier och pingar, en simulerad Cisco IOS-konsol, jämförelse med alternativ, installationsguide och quiz.

Öppna `index.html` i en webbläsare – inga beroenden eller byggsteg behövs.
